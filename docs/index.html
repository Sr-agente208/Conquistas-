Painel do Conquistas

Botões para executar, console ao vivo e histórico — a versão “abrir e usar”. Ele roda no seu computador, não aqui: a automação precisa de uma janela de navegador de verdade.

Abrir painel ↗
Como ligar o painel
  1. pip install -e ".[dev]" && playwright install chromium
  2. conquistas serve

Abre em 127.0.0.1:8765. Para usar do celular na mesma rede: CONQUISTAS_ALLOW_PUBLIC=1 conquistas serve --host 0.0.0.0 e acesse http://IP-DO-PC:8765 — só em rede confiável.

Como usar

  1. Busque pelo nome do projeto, pelo autor ou por uma palavra da descrição — acentos não importam.
  2. Filtre tocando em uma linguagem na barra do topo (ex.: Python, TypeScript) e toque em “Todos” para voltar.
  3. Ordene por estrelas, por atualização recente, por forks ou por nome.
  4. Abra o cartão para ir ao repositório no GitHub, em uma nova aba.

No celular, o menu do navegador → Adicionar à tela de início deixa a lista como um atalho. Sem internet? Baixe a versão em arquivo único e abra direto no navegador — ela já vem com os dados embutidos.

Antes de usar qualquer um deles

Automatizar os pontos viola o Contrato de Serviços da Microsoft e pode levar à suspensão da conta. Estes são projetos de terceiros, sem qualquer vínculo com a Microsoft ou com o Conquistas: leia o código e o README antes de executar, e nunca informe sua senha fora do site oficial.
